Источники версий: npm lockfile и Docker image digests в каждом комплекте.
Проверяемый путь QA: настоящий LibreChat UI через custom endpoint вызывает учебный
backend на настоящем @librechat/agents. Не использован отдельный демонстрационный Python-агент.
Mock не доказывает качество поведения настоящей модели.

Не проверено и требует действий организатора:
- реальная 1С: с версии задания 2.1 её самостоятельно разворачивает кандидат;
  до старта нужно подтвердить доступ к дистрибутиву и лицензии;
- настоящая модель и coding agent (не предоставлены доступы/квоты);
- Mac/Windows/ARM и удалённый резервный стенд;
- GitHub Actions: workflow добавлен; локальные проверки не равны удалённому CI-прогону.

Повторяемый smoke: команды в README каждой папки; CI запускает те же проверки.
Браузерный прогон выполнен вручную через автоматизацию; обязательный браузерный
тест по QA-заданию пишет кандидат. Скриншоты/локальные трассы не входят в кандидатские архивы.

Изменение условий full-stack, версия 2.1: установка и подготовка 1С перенесены
на кандидата, выделено до 4 часов дополнительно к 12 часам разработки. Проверены
согласованность README/контракта и текст обеих копий PDF; просмотрены все четыре
страницы после рендеринга. Код окружений не менялся.

Требование сдачи через собственный GitHub-репозиторий добавлено во все три PDF
и README. Проверены текст, ссылки на сдачу, совпадение корневых и вложенных PDF
и вёрстка последних страниц. Версии: full-stack 2.2, ML/MLOps и QA/SDET 2.1.
